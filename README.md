# 📱 SimCard Collector

Добро пожаловать в **SimCard Collector** — увлекательную Telegram Mini App игру, где вы можете покупать виртуальные сим-карты, открывать номера разной степени редкости и собирать уникальную коллекцию!

## 🎮 Как играть?

1. **Покупайте симки** в магазине за внутриигровую валюту (₽).
2. **Открывайте номера**: каждый раз вам выпадает случайный номер. Чем выше редкость, тем он дороже!
3. **Собирайте коллекцию**: обычные, редкие и легендарные номера.
4. **Продавайте номера**: если номер вам не нужен, вы можете продать его и получить деньги обратно.
5. **Заходите каждый день**: получайте ежедневный бонус и поддерживайте свой стрик (до 7 дней).
6. **Покупайте улучшения**: используйте Telegram Stars, чтобы получить x2 удачу, дополнительные деньги или гарантированный легендарный номер.(В разработке)
7. **Активируйте промокоды**: следите за новостями в нашем Telegram-канале, чтобы не пропустить бонусы!

## ✨ Особенности

- 📱 Полноценная **Telegram Mini App** интеграция (работает внутри мессенджера).
- 💎 **Система редкости**: обычные, редкие и легендарные номера.
- 💰 **Экономика**: покупка, продажа и ежедневные бонусы.
- 🎁 **Улучшения за звёзды**: x2 удача, денежные бусты и легендарные номера.
- 🎟️ **Промокоды**: активация уникальных кодов (с лимитом использований).
- 🛡️ **Админ-панель**: встроенная панель управления для администратора игры (баланс, шансы, промокоды, выдача номеров).
- 🌙 **Современный дизайн**: тёмная тема, стеклянные элементы (glassmorphism), плавные анимации.

## 🚀 Как запустить локально?

Проект представляет собой **статический сайт**, поэтому запустить его можно очень просто.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/servo-spec/servo-spec.github.io.git
   2. Откройте файл index.html в любом современном браузере.
3. Для проверки функционала Telegram (кнопки, окна оплаты) рекомендуем использовать Telegram Web с установленным Mini App.

🛠️ Технологии

· HTML5 / CSS3 (кастомный дизайн, анимации, CSS-переменные)
· Vanilla JavaScript (логика игры, работа с localStorage)
· Telegram Web Apps SDK (интеграция с Telegram)

⚠️ Важно знать

На данный момент проект использует localStorage для сохранения прогресса, что означает, что данные привязаны к конкретному браузеру/устройству.

Для реального запуска и монетизации потребуется перенос логики (баланс, коллекция, оплата) на серверную часть (Backend) для предотвращения читерства и безопасного приёма платежей (Telegram Stars / крипта / карта).
